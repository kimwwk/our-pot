**Priority:** Critical
**Issue:** All tab content overlaps with mobile status bar (time, battery, signal). Pot switcher cannot be pressed.
**Fix:** Add top padding/margin to prevent overlap.

- [ ] Add safe-area-inset-top padding to all tab containers
- [ ] Test pot switcher is clickable on iOS/Android devices
- [ ] Verify all tabs have proper top spacing

**Done When:** No content overlaps status bar, pot switcher is always clickable.

### 3. Standardize Form Components

#### 3.1 Currency Amount Input
**Issue:** Amount display varies across expense/contribution forms. Should auto-align to account currency.
**Fix:** Create reusable CurrencyInput component.

- [ ] Create `components/ui/CurrencyInput.tsx`:

  - Automatically formats to account currency
  - Converts display ↔ cents
  - Consistent styling across all forms
- [ ] Replace amount inputs in:
  - [ ] Add/Edit Expense sheet
  - [ ] Add/Edit Contribution sheet
  - [ ] Anywhere else displaying amounts

**Done When:** All currency inputs look identical and auto-format to account currency.

#### 3.2 Member Picker Component
**Issue:** "Who is contributing" and "Paid by" have different implementations.
**Fix:** Create reusable MemberPicker component.

- [ ] Create `components/ui/MemberPicker.tsx`:
  - Accepts members array as prop (no domain knowledge)
  - Caller filters out kitty if needed
  - Consistent styling
  - Single/multi-select support
- [ ] Replace member pickers in:
  - [ ] Expense "Paid by" field
  - [ ] Contribution "Who is contributing" field
- [ ] Ensure kitty filtering happens in parent component, not MemberPicker

**Done When:** Both pickers use same component with consistent UX.
