## Critical Issues

### 1. Mobile Status Bar Overlap
**Priority:** Critical
**Issue:** Pot switcher in header overlaps with mobile status bar (time, battery, signal) and cannot be pressed.
**Fix:** Add safe-area-inset-top padding to the sticky header element only (not all containers).

- [x] Add `pt-[env(safe-area-inset-top,0px)]` to header in `app/(tabs)/layout.tsx`
- [x] Test pot switcher is clickable on iOS/Android devices
- [x] Verify header respects status bar on mobile

**Done When:** No content overlaps status bar, pot switcher is always clickable.
